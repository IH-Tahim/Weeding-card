# Lal Paar — Hindu wedding, red & white, light the diya

Dark opening screen with a clay diya. The guest presses and holds for about 1 second while a gold ring fills, the flame lights, and a warm glow fills the screen.
Then a red-and-white Lal Paar saree-border card opens with a turning alpana, "॥ শ্রী শ্রী প্রজাপতয়ে নমঃ ॥", শুভ বিবাহ, both families, a ceremony list with red date blocks, countdown, RSVP and contacts.
It opens in Bangla by default (`defaultLang: "bn"`).

**Per client:** edit only `data.js`. It uses the same format as the other designs, plus an optional `blessing` line. Set `showBismillah: false`.
A "Open without lighting" link is there for guests who just want to see the card.

The link generator, RSVP sheet setup and publishing steps are the same as in `../royal-envelope/README.md`.
