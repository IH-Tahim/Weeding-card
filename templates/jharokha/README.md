# Jharokha — a Mughal palace window

- **Opening:** a carved marble **jharokha** (palace window) with gold **jali lattice shutters**. They swing open and the view **zooms through the cusped arch** into the card.
- **Page:** marble with faint star-lattice, ruby / emerald / gold **pietra-dura inlay** dividers, names inside a cusped arch with optional degree / profession lines.
- Octagonal countdown tiles, events as **arched alcove cards**, the couple photo in an arch.

Per client: edit `data.js` only (names, `title` for degree/profession, events, extras). Guest links: `index.html?to=Name` (add `&lang=bn` for Bangla).
Built on the shared engine (`../shared/core.js`) with the shared extras (`../shared/extras.js`: calendar + Bangla date, story, programme, dress code, menu, gifts, stay, FAQ) and media (`../shared/media.js`: music, map, calendar, share).
