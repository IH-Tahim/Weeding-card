# Polaroid Memories — scrapbook, swipe the photos

A stack of Polaroids on a wooden table. The guest swipes each love-story photo away (or taps). The last card is the invitation note.
Then a scrapbook page: taped Polaroid, date stamp, a story strip, notebook-paper families, ticket-stub events, a sticky-note countdown and a postcard RSVP.

Per client: edit `data.js` and set `story` (up to 3 photos with captions) and `photo`.
