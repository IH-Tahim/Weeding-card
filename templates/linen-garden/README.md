# Linen Garden — inspired by the trending sage-linen gatefold style

- **Opening:** two sage **linen doors** with raised leaf embroidery and an ornate cream **plaque** with the monogram. Tap and the doors swing open.
- **Page:** woven linen paper framed on both sides by **embroidered rose vines**.
- **Names** in calligraphy with parents and an optional **degree / profession** line (`groom.title`, `bride.title`).
- **Scratch the heart** to reveal the date (with little hearts bursting out), then Add to calendar.
- Couple photo in an arch, countdown tiles, a **programme timeline grouped by day** with map and save buttons.

Per client: edit `data.js` only (names, `title` for degree/profession, events, extras). Guest links: `index.html?to=Name` (add `&lang=bn` for Bangla).
Built on the shared engine (`../shared/core.js`) with the shared extras (`../shared/extras.js`: calendar + Bangla date, story, programme, dress code, menu, gifts, stay, FAQ) and media (`../shared/media.js`: music, map, calendar, share).
