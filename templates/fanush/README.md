# Fanush — sky lanterns at night

- **Opening:** dusk over a river ghat with a boat; the guest taps the glowing **fanush** and it floats up into the sky.
- **Page:** a fixed sky that **deepens from dusk to night as the guest scrolls**, stars, and lanterns that keep rising. **Tap anywhere in the sky to release a lantern.**
- Glass cards, a large date with the Bangla date and countdown, event cards hanging from lanterns.
- Each RSVP sends a lantern up with the reply.

Per client: edit `data.js` only (names, `title` for degree/profession, events, extras). Guest links: `index.html?to=Name` (add `&lang=bn` for Bangla).
Built on the shared engine (`../shared/core.js`) with the shared extras (`../shared/extras.js`: calendar + Bangla date, story, programme, dress code, menu, gifts, stay, FAQ) and media (`../shared/media.js`: music, map, calendar, share).
