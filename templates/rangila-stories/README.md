# Rangila Stories — Bangla folk art, story slides

Colourful rickshaw/truck-art style. Painted doors swing open, then the invitation plays like Instagram stories:
progress bars at the top, tap right for next and left for back, swipe, and hold to pause. Slides move on by themselves every 7 seconds and stop at the RSVP and the last slide.
Great for Gaye Holud and fun, young couples.

Slides: names → families → one slide per event → countdown → photos (if any) → RSVP → thank you + contacts.

**Per client:** edit only `data.js`. It uses the same format as Royal Envelope, so the same client data works in every design.
Optional per event: `icon: "🌼"` sets the emoji. Otherwise it is picked automatically from the event name.

The link generator, RSVP sheet setup and publishing steps are the same as in `../royal-envelope/README.md`.
