# Nakshi Kantha — hand-stitched Bangla heritage

- **Opening:** an embroidery hoop. The guest taps the **thread spool** and a **lotus medallion is stitched petal by petal** while a needle moves around it.
- **Page:** cotton quilt texture, **running-stitch borders** in madder red, indigo, turmeric and green, kantha motifs (bird, fish, paisley, leaf).
- Every event is a colourful **kantha patch** with the **Bangla calendar date** (বঙ্গাব্দ).
- Opens in Bangla by default (`defaultLang: "bn"`).

Per client: edit `data.js` only (names, `title` for degree/profession, events, extras). Guest links: `index.html?to=Name` (add `&lang=bn` for Bangla).
Built on the shared engine (`../shared/core.js`) with the shared extras (`../shared/extras.js`: calendar + Bangla date, story, programme, dress code, menu, gifts, stay, FAQ) and media (`../shared/media.js`: music, map, calendar, share).
