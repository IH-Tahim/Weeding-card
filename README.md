# Digital Wedding Invitation Cards

Mobile-first wedding invitation websites for Bangladesh: an animated envelope opening, a personal greeting for each guest, English and Bangla, events with directions, a countdown and RSVP.

## Templates
| Template | Style | Folder |
|---|---|---|
| Royal Envelope | Classic ivory & gold, tap the wax seal | [`templates/royal-envelope`](templates/royal-envelope) |
| Rangila Stories | Colourful Bangla folk art, story slides | [`templates/rangila-stories`](templates/rangila-stories) |
| Midnight Scratch | Navy & gold luxury, scratch to reveal | [`templates/midnight-scratch`](templates/midnight-scratch) |
| Emerald Scroll | Islamic emerald & gold, pull to unroll | [`templates/emerald-scroll`](templates/emerald-scroll) |
| Lal Paar | Hindu wedding, red & white, light the diya | [`templates/lal-paar`](templates/lal-paar) |
| Rose Arch | Trending: embossed seal envelope, misty rose arch, hanging date, event carousel | [`templates/rose-arch`](templates/rose-arch) |
| Silk Ribbon | Modern blush & champagne, untie the bow | [`templates/silk-ribbon`](templates/silk-ribbon) |
| Polaroid Memories | Scrapbook photo story, swipe the Polaroids | [`templates/polaroid-memories`](templates/polaroid-memories) |

Showcase: https://ih-tahim.github.io/Weeding-card/

Every design includes soft fade-in music, a couple photo or illustration, a live venue map, save-the-date with reminders, RSVP and named guest links (see `templates/shared/README.md`).

See each template's README for how to make a card for a client.
