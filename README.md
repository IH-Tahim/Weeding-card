# Digital Wedding Invitation Cards

Mobile-first wedding invitation websites for Bangladesh: an animated envelope opening, a personal greeting for each guest, English and Bangla, events with directions, a countdown and RSVP.

Every design includes soft fade-in music, a couple photo or illustration, a live venue map, save-the-date with reminders, RSVP and named guest links, plus optional extra sections from `data.js → extras`: a month calendar with the **Bangla (বঙ্গাব্দ) date**, our story, programme, dress-code colours, feast menu, gifts (bKash), hotels and FAQ (see `templates/shared/README.md`).

See each template's README for how to make a card for a client.
